# 해 지기 전에 (Before Sundown) — 게임 데이터

> 무기, 아이템, 캐릭터, 동물, 장소별 파밍 같은 **목록과 수치**를 모은 문서다.
> 이야기는 `docs/story.md`, 작업 규칙과 핵심 시스템은 `CLAUDE.md`를 따른다.
> 모든 숫자는 **시작값**이다. 플레이테스트하면서 조절하고, 바꾸면 이 문서도 함께 고친다.
> 칸 크기는 가방 격자 기준 "가로 x 세로"다.

---

## 1. 근접 무기

유형: PUSH(밀어내기) / KNOCKDOWN(넘어뜨리기) / KILL(처치) / LURE(유인)
밤에는 KILL 무기도 넘어뜨리기까지만 된다 (총 제외).

| 무기 | 얻는 곳 | 유형 | 칸 | 맞을 때 소리 / 소음 | 특징 |
|---|---|---|---|---|---|
| 죽도 | 1장 검도부 동아리방 | PUSH | 1x5 | 기합 "머리!" "손목!" "허리!" / 중간 | 공격이 빠름, 거의 안 부러짐. 좀비는 한 걸음 밀렸다 다시 옴 |
| 야구배트 | 1장 야구부 동아리방 | KNOCKDOWN | 1x4 | "땡~" / 큼 | 크게 날려 보냄, 넘어짐 2초. 시간을 가장 많이 벌어 줌 |
| 프라이팬 | 1장 학생식당 주방 | KNOCKDOWN | 2x3 | "깡!" / 큼 | 배트보다 짧게 날려 보냄, 넘어짐 1.5초 |
| 식칼 | 1장 학생식당 주방 | KILL | 1x2 | 작음 / 작음 | 빠르지만 금방 부러짐, 처치에 4번 |
| 큰 스패너 | 1장 자동차학과 실습동 (선택) | KNOCKDOWN (낮에는 KILL) | 1x3 | "깡!" / 중간 | 튼튼함, 처치에 3번 |
| 짧은 빠루 (타이어 레버) | 1장 자동차학과 실습동 (선택) | KILL (약함) | 1x2 | 둔탁 / 중간 | **문과 셔터 열기 가능**. 처치에 4번 |
| 빠루 | 4장 철물점 | KILL | 1x4 | 둔탁 / 중간 | 느리지만 강함, 처치에 2번. **문과 셔터, 철장 열기** |
| 등산 스틱 | 4장 등산용품점 | PUSH | 1x3 | 작음 / 작음 | 죽도보다 약하지만 짧아서 가방에 잘 들어감 |
| 군용 삽 (접이식) | 5장 군 검문소 | KILL | 1x3 | 중간 / 중간 | 속도와 힘이 균형, 처치에 3번 |
| 나무 막대기 | 7장 숲 | PUSH | 1x3 | 작음 / 작음 | 금방 부러짐 |
| 곡괭이 | 8장 터널 정비 창고, 9장 농가 창고 | KILL | 3x4 | 큼 / 큼 | 아주 느림, 아주 강함 (처치 1~2번). **돌무더기 치우기** |
| 낫 | 9장 비닐하우스 | KILL | 2x2 | 작음 / 작음 | 빠르지만 사거리 짧음, 처치에 3번 |
| 삽 (농기구) | 9장 헛간 | KILL | 1x4 | 중간 / 중간 | 사거리가 길어 거리를 두고 때림, 처치에 3번 |
| 도끼 | 9장 장작더미 옆 | KILL | 2x3 | 큼 / 큼 | 느리지만 한두 번이면 쓰러뜨림 |

## 2. 원거리 무기와 던지는 물건 (보조 칸, 마우스 오른쪽)

| 이름 | 얻는 곳 | 효과 | 칸 / 탄 | 소음 |
|---|---|---|---|---|
| 돌 | 숲, 농촌 등 어디서나 | 피해 없음. 떨어진 곳에서 소리로 좀비 유인. 좀비에게 맞아도 그냥 걸어감 | 1x1, 3개까지 겹침 | 작음 (떨어진 곳) |
| 빈 병 | 편의점, 골목 | 피해 없음. 깨지는 소리로 더 멀리 있는 좀비까지 부름 | 1x1, 2개까지 | 중간 (떨어진 곳) |
| 폭죽 | 4장 마트 (드묾), 10장 직전 하나 | 피해 없음. 몇 초 동안 계속 터지며 번쩍여서 좀비 떼를 한곳에 묶어 둠 | 1x1, 2개까지 | 큼, 지속 |
| 권총 | 4장 경찰서 무기 보관함 (경찰관을 구출해 열쇠를 받아야 함) | 한 발에 처치. **밤에도 처치 가능** | 1x2 / 권총탄 1x1, 6개까지 겹침, 한 판에 6~10발 | 매우 큼 |
| 공포탄 소총 | 5장 군 검문소 | 피해 없음. 가까운 좀비 2초 놀람, **맵 전체 좀비가 쏜 자리로 몰려와 20~30초 수색 후 한 마리씩 흩어짐** | 1x5 / 공포탄 1x1, 한 판에 3~5발 | 맵 전체 |
| 엽총 | 9장 엽사 할아버지가 넘겨줌 | 부채꼴 산탄으로 여러 마리를 처치하고 밀어냄. 밤에도 처치 가능 | 1x4 / 산탄 1x1, 6개까지 겹침, 한 판에 4~6발 | 매우 큼 |

- 총을 쏠 때는 총구에서 빛이 잠깐 번쩍인다.
- 총의 소음은 밤에 더 멀리 퍼진다.

## 3. 무기 강화

- **작업대**가 있는 안전 쉼터에서 강화한다 (게임 정지).
- 무기마다 ★1 → ★2 → ★3. 무기를 바꾸면 강화는 사라진다.
- 강화 재료도 가방 칸을 차지한다.

| 재료 | 칸 | 얻는 곳 |
|---|---|---|
| 청테이프 | 1x1, 3개까지 | 동아리방, 철물점, 마트 |
| 못 | 1x1, 5개까지 | 철물점, 자동차학과 |
| 철사 | 1x1, 3개까지 | 철물점, 농가 창고 |
| 고무 손잡이 | 1x1 | 등산용품점, 자동차학과 |
| 쇠파이프 조각 | 1x2 | 자동차학과, 터널 정비 창고 |

| 무기 | ★2 (재료) | ★3 (재료) |
|---|---|---|
| 야구배트 | 테이프 감은 배트: 내구도 증가 (청테이프 1) | 못 박힌 배트: 넉백 거리 증가 (못 3) |
| 죽도 | 고무 손잡이: 공격 속도 증가 (고무 손잡이 1) | 쌍죽도: 한 번에 두 번 때림 (죽도 1 + 청테이프 2) |
| 프라이팬 | 손잡이 보강: 내구도 증가 (청테이프 1) | 무쇠 프라이팬: 넘어지는 시간 증가 (철사 2) |
| 빠루 | 고무 손잡이: 휘두르는 속도 증가 (고무 손잡이 1) | 강화 빠루: 처치 타격 수 1 감소 (쇠파이프 조각 1 + 철사 1) |
| 큰 스패너 | 손잡이 감기: 내구도 증가 (청테이프 1) | 무게 추: 넘어짐 시간 증가 (쇠파이프 조각 1) |

## 4. 방어구

- 방어구 칸은 손 칸과 따로 있다. 좀비에게 맞으면 **에너지 대신 방어구가 깎이고 상처도 생기지 않는다.**
- 막는 횟수를 다 쓰면 "퍽!" 하고 벗겨진다. 작업대에서 청테이프나 스카치테이프로 수리할 수 있다.

| 방어구 | 얻는 방법 | 막는 횟수 | 특징 |
|---|---|---|---|
| 도마 | 1장 학생식당 주방 | 1 | 방패처럼 몸 앞에 듦 |
| 골판지 팔 보호대 | 조합: 골판지 1 + 스카치테이프 1 | 1 | 가볍고 빨리 만듦 |
| 골판지 갑옷 | 조합: 골판지 2 + 스카치테이프 1 | 2 | 뛰면 "바스락" 작은 소음. 캐릭터마다 낙서가 다름 (축제 부스 글씨) |
| 잡지 팔 보호대 | 조합: 잡지 2 + 스카치테이프 1 | 2 | 2장 편의점, 골목에서 잡지를 구함 |
| 두꺼운 등산 재킷 | 4장 등산용품점 | 3 | 소리 안 남 |
| 방검 조끼 | 5장 군 검문소 | 4 | 무거워서 살짝 느려짐 |

| 조합 재료 | 칸 | 얻는 곳 |
|---|---|---|
| 골판지 | 1x2, 3개까지 | 1장 동아리방 (축제 부스 상자), 편의점 창고, 마트 |
| 스카치테이프 | 1x1, 3개까지 | 1장 동아리방, 편의점 |
| 잡지 | 1x1, 2개까지 | 2장 편의점, 골목 |

## 5. 회복과 소모 아이템

| 아이템 | 칸 | 효과 | 얻는 곳 |
|---|---|---|---|
| 통조림 | 1x1 | 에너지 +1, 배고픔 초기화 | 주방, 편의점, 마트, 무너진 대피소 |
| 컵라면 | 1x1 | 에너지 +1, 배고픔 초기화 | 편의점, 마트 |
| 과자 | 1x1, 2개까지 | 배고픔 1시간 늦춤 | 편의점, 자판기 옆 |
| 에너지바 | 1x1, 2개까지 | 배고픔 2시간 늦춤 | 4장 등산용품점 |
| 전투식량 | 1x2 | 에너지 +2, 배고픔 초기화 | 5장 군 검문소 |
| 새참 | 1x1 | 에너지 +1, 배고픔 초기화 | 9장 농가 |
| 음료 | 1x1 | 에너지 +1, 배고픔 1~2시간 늦춤 | **자판기 (동전 1개, 뽑을 때 "덜컹" 소음)**, 편의점 냉장고 |
| 약 | 1x1 | 에너지 +2. **상처는 치료 못 함** | 보건실, 약국, 4-B 병원 |
| 구급상자 | 1x2 | **상처 치료** (한지아는 에너지 +1까지) | 1장 체육관 대피소, 약국 (드묾), 4-B 병원 (여러 개) |
| 동전 | 가방 안 차지 (개수만) | 자판기, 교환 | 계산대, 서랍, 차 안, 자동차 밑 |
| 고양이 간식 (참치캔, 츄르) | 1x1, 2개까지 | 고양이 친밀도 증가 | 편의점, 마트 |
| 강아지 간식 (육포, 소시지) | 1x1, 2개까지 | 강아지 친밀도 증가 | 편의점, 마트, 휴게소 |

- 가방을 얻기 전(1장 초반)에는 음식, 약, 보조배터리를 주우면 **바로 사용**한다.

## 6. 도구와 장비

| 아이템 | 칸 | 쓰임 | 얻는 곳 |
|---|---|---|---|
| 휴대폰 | 가방 안 차지 | 불빛, 카톡, 게시판, 지도. 배터리 소모 | 시작 |
| 보조배터리 | 1x2 | 휴대폰 충전 | 1장 동아리방 (하람 시작 아이템), 편의점 |
| 건전지 | 1x1, 4개까지 | 손전등, 헤드랜턴, 작업등 충전 | 편의점, 철물점, 무너진 대피소 |
| 작업등 | 1x2 | 휴대폰보다 넓게 비추는 손전등 | 1장 자동차학과 실습동 (선택) |
| 손전등 | 1x2 | 넓고 멀리 비춤 | 4장 철물점 |
| 헤드랜턴 | 1x1 | 손이 자유로운 불빛 (머리에 착용) | 4장 등산용품점 |
| 절단기 | 1x3 | **철조망 자르기** | 4장 철물점 |
| 무전기 | 가방 안 차지 | 김 반장 방송 듣기 (잡음 심함) | 1장 경비실 |
| 군 무전기 | 가방 안 차지 | 무전이 선명해짐 | 5장 군 검문소 |
| 기관사 대기실 열쇠 | 가방 안 차지 | 3장 안전 쉼터 열기 | 3장 역무원 아저씨 |
| 무기 보관함 열쇠 | 가방 안 차지 | 4장 경찰서 권총 | 4장 구출한 경찰관 |

## 7. 가방

| 가방 | 크기 | 얻는 곳 |
|---|---|---|
| 없음 | 손 칸 1 + 방어구 칸 1 | 1장 초반 |
| 학생 백팩 | 4x3 | 1장 학생회관 분실물 보관함 |
| 등산 배낭 | 7x5 | 4장 등산용품점 (셔터를 빠루로 열어야 함) |

- 이태오는 가방이 한 줄 작다 (학생 백팩 4x2, 등산 배낭 7x4).

## 8. 잠긴 곳과 필요한 도구

| 막힌 곳 | 필요한 것 | 장소 |
|---|---|---|
| 잠긴 문, 셔터 | 빠루 또는 짧은 빠루 | 편의점 창고, 등산용품점, 역무실 등 |
| 동물병원 철장 | 빠루 (여는 소리에 좀비가 몰려옴) | 4장 동물병원 |
| 철조망 | 절단기 | 4장 철물점 뒤 골목 (연습용 지름길), 7장 임도 입구 |
| 돌무더기 | 곡괭이 | 8장 터널 안 대피소 |
| 기관사 대기실 | 기관사 대기실 열쇠 | 3장 |
| 경찰서 무기 보관함 | 무기 보관함 열쇠 | 4장 |

- 도구가 없을 때 조사하면 혼잣말이 나온다. 예: "자를 도구가 있었으면…"

## 9. 휴대폰 배터리와 충전

| 항목 | 값 |
|---|---|
| 배터리 | 0~100% |
| 불빛을 켜 두면 | 게임 속 1시간에 약 15% 소모 (어두운 구간에서만) |
| 지도 앱 | 켜 두는 동안 1시간에 약 5% |
| 카톡·게시판 열기 | 한 번에 1% |
| 20% 이하 | 불빛이 깜빡이고 좁아짐 |
| 0% | 불빛 꺼짐, 받은 메시지는 쌓였다가 충전되면 한꺼번에 알림 |

| 충전 수단 | 장소 | 특징 |
|---|---|---|
| 보조배터리 | 1장, 편의점 | 언제든 사용, +50% |
| 비상발전기 콘센트 | 3장 역무실 (위험 쉼터) | 자는 동안 100%까지 |
| 자동차 USB | 5장 대교, 8-B 임도의 버려진 차 | 차에 타면 충전. **잘못 건드리면 경보** |
| 태양광 콘센트 | 9장 농가, 비닐하우스 | 낮에만 충전 |
